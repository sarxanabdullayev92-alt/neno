# Демо для клиента: мастер едет к клиенту по линии маршрута

Показывает главное: иконку мастера, линию маршрута, «км · мин» и движение
мастера каждые 15 секунд. Работает в Test Mode, геолокация браузера не нужна.

**Как это устроено:** скрипт на сервере (`/opt/geo/demo/demo_drive.py`)
ставит «Тест Мастера» в Сокольниках, создаёт демо-заказ **№ 900001** с адресом
на Манежной площади и каждые 15 секунд двигает мастера по реальному маршруту
(≈ 7,8 км, поездка 5 минут). Приложения видят движение как настоящее.

Скрипт запускаю я — напишите в чат, какое демо запустить.

---

## Демо 1 — экран клиента

### Один раз: временная кнопка «Демо» в nado_clean

MapPage → добавить **Button** с текстом «Демо» (куда угодно, например над
картой) → Actions → **On Tap**:

1. **Update App State** — четыре поля, все **Specific Value**:

   | Поле | Значение |
   |---|---|
   | `activeOrderId` | `900001` |
   | `activeMasterId` | `11` |
   | `orderLat` | `55.756` |
   | `orderLng` | `37.615` |

2. **Navigate To** → `MapPage` (страница перезагрузится и подпишется на заказ).

После показа кнопку удалить.

### Показ

1. Напишите в чат: **«запусти демо клиента»**. Я запущу скрипт.
2. В Test Mode клиента нажмите **«Демо»**.
3. Видно:
   - красную булавку клиента на Манежной площади;
   - иконку мастера в Сокольниках (в синей рамке — это «ваш» мастер);
   - синюю линию маршрута и плашку «7,8 км · N мин»;
   - мастер каждые 15 секунд сдвигается по линии, раз в минуту линия
     перестраивается от его новой точки и становится короче.
4. Через ~5 минут мастер доезжает, заказ завершается — карта сама
   возвращается к списку всех мастеров.

## Демо 2 — экран мастера

Ничего добавлять в FlutterFlow не нужно.

1. Test Mode мастера → войти `test.master@nadoclean.ru` / `MasterTest2026!`.
2. **Запретить браузеру геолокацию** для этой вкладки (иначе приложение будет
   отправлять вашу реальную позицию и мастер будет «прыгать»).
3. WorkMain → включить **«Смену»**.
4. Напишите в чат: **«запусти демо мастера»**.
5. Через пару секунд сама откроется страница **«Предложение заказа»** —
   это оповещение о новом заказе.
6. Нажмите **«ПРИНЯТЬ ЗАКАЗ»** → откроется «Заказ в работе» с картой:
   иконка мастера, булавка клиента, линия маршрута, «км · мин».
7. Мастер едет к клиенту 5 минут. В конце нажмите **«ЗАВЕРШИТЬ РАБОТУ»**.

> На «Предложении заказа» строки «Расстояние» и «В пути» будут «—»:
> они считаются от геолокации телефона, а в браузере она запрещена.
> На телефоне там будут реальные цифры.

---

## Оба экрана сразу

Две вкладки: клиент (с кнопкой «Демо») и мастер (шаги 1–3 из Демо 2).
Напишите **«запусти демо мастера»**, примите заказ у мастера, затем нажмите
«Демо» у клиента — оба увидят одного и того же мастера, едущего по линии.

## Команды (для справки)

```bash
ssh -i ~/.ssh/nado_clean root@159.194.254.20
cd /opt/geo/demo
python3 demo_drive.py client             # демо клиента, 5 минут
python3 demo_drive.py client --minutes 3 # быстрее
python3 demo_drive.py master             # демо мастера, ждёт «ПРИНЯТЬ» 10 минут
python3 demo_drive.py reset              # убрать демо-заказ
```

Проверено 14.09: оба режима и reset прогнаны на сервере — заказ создаётся,
мастер проходит маршрут 7,8 км, в режиме client заказ получает статус done.
